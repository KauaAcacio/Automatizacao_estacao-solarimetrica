# User Story - Enviar as novas informações para o banco de dados

## Descrição

Como usuário da Estação Solarimétrica, eu quero enviar as novas informações obtidas da estação compacta para um banco de dados, para que eu possa usar esses dados organizados na criação de um site.

## Critérios de aceitação

- Os dados precisam estar armazenados em uma classe.
- É necessário que exista os dados.
